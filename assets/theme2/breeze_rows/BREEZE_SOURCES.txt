Rendered from the 22px SVGs (after following the repository's symlinks) to
44x44 RGBA PNG (192 DPI) with ImageMagick, every color replaced by one flat
tint: the average color of the stock icon each file replaces, so rows keep
their colors.

A file here named <folder>_<name>.png replaces <folder>/<name>.png on
category rows (decorate_category_row()) unless the active theme supplies
that image; the stock icon stays the fallback.
