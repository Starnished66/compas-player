Breeze title-bar icons

Rendered from the 22px SVGs straight to 44x44 RGBA PNG (192 DPI) with
ImageMagick. Every Breeze colour, including the red of edit-delete, is
replaced so each file is pre-tinted: <name>.png in Breeze's text colour for
dark surfaces (#fcfcfc) and <name>_dark.png in its text colour for light ones
(#232629). The player picks the variant matching the theme text colour and
only recolours at runtime while "Tint title bar icons" (accent) is on.

Mapping (icons/<path>, after following the repository's symlinks):
  breeze_back.png      <- actions/22/go-previous.svg
  breeze_search.png    <- actions/22/edit-find.svg
  breeze_menu.png      <- actions/22/application-menu.svg
  breeze_sound.png     <- status/22/audio-volume-high.svg
  breeze_playback.png  <- actions/22/view-media-equalizer.svg
  breeze_database.png  <- places/22/server-database.svg (network-server-database.svg)
  breeze_delete.png    <- actions/22/edit-delete.svg
  breeze_download.png  <- actions/22/download.svg (edit-download.svg)
  breeze_refresh.png   <- actions/22/view-refresh.svg
  breeze_favorite.png  <- emblems/22/emblem-favorite.svg (rating.svg)
  breeze_favorite_off.png <- emblems/22/rating-unrated.svg
  breeze_handle.png    <- actions/22/handle-sort.svg, padding trimmed to fill the
                          reorder grip (replaces navigation/reorder.png)

Used in place of these title-bar assets, which remain the fallback:
  navigation/back.png, navigation/search.png, navigation/more.png,
  settings/sound.png, settings/playback.png, submenu/music_database.png,
  playlist_actions/trash.png, stream_media/download.png,
  playing_plane/collect_in.png, playing_plane/collect_out.png
  (text reader title bar), and the LV_SYMBOL_REFRESH glyph of the
  title-bar refresh action.
