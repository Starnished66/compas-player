Main submenu assets (2026-09-13)
Runtime path: /usr/resource/litegui/theme2/submenu/
Icons 44x44 RGBA, from Phosphor Icons @2.1.1 (MIT).
Sources: folder-open, user, vinyl-record, user-square, music-notes-simple,
playlist, cloud-arrow-down, usb, bluetooth, book-open, bookmark-simple,
arrows-clockwise, database, tag, images-square.
SVG gradients follow the Settings/Wireless gold/cyan/mint/silver/purple/coral
palette. Rendered via ffmpeg librsvg and Lanczos size export.
update_database.png uses the regular arrows-clockwise glyph from
@phosphor-icons/core 2.1.1 (assets/regular/arrows-clockwise.svg), MIT.
music_database.png (gold) and refresh_metadata.png (coral) use the regular
database and tag glyphs from the same package, vertical gradient, rendered at
176px and Lanczos-scaled to 44px.
refresh_covers.png (purple) uses the regular images-square glyph from
@phosphor-icons/core 2.1.1 (assets/regular/images-square.svg), vertical
gradient, rendered at 176px and Lanczos-scaled to 44px.
Saved backgrounds reuse the generated Settings and Wireless gradients.
Rows retain decoded images for their lifetime. No runtime gradient generation.

More-menu additions, rebuilt with python3 scripts/generate_more_menu_icons.py:
plugins.png uses @phosphor-icons/core@2.1.1 assets/regular/puzzle-piece.svg
with the violet Settings gradient (#d7a9fa to #a36be4).
themes.png uses assets/regular/palette.svg with a gold-to-coral gradient
(#ffda85 to #ee7c83).
layouts.png uses assets/regular/squares-four.svg with a cyan-to-mint gradient
(#95d7f0 to #45c4a1).
The SVG paths are from the package's MIT-licensed regular icon assets; the
same existing MIT License in this directory applies. USB DAC and Bluetooth
DAC reuse the existing usb.png and bluetooth.png originals above.

genres.png uses the regular tag glyph from @phosphor-icons/core 2.1.1
(assets/regular/tag.svg), coral vertical gradient (#ffb4a2 to #ee7c83),
rendered at 176px and Lanczos-scaled to 44px. See LICENSE for MIT terms.
